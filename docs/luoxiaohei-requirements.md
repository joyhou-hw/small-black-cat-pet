# 罗小黑桌面宠物 — 需求分析文档

> **文档版本**：v1.0
> **日期**：2026-11-05
> **目标平台**：Android（华为P30，EMUI 9.1 / Android 9 API 28）

---

## 一、目标用户画像

| 维度 | 描述 |
|---|---|
| 年龄 | 初中生（约12-15岁），未成年 |
| 性别 | 女 |
| 偏好 | 喜欢罗小黑（黑猫角色，出自国产动画《罗小黑战记》） |
| 设备 | 华为P30，EMUI 9.1（Android 9，API 28），6.1英寸OLED，6GB RAM，128GB ROM，麒麟980 |
| 使用场景 | 日常陪伴 + 学习辅助 + 手机使用管理 |
| 核心诉求 | 不是一个冷冰冰的AI工具，而是一只"住在手机里的猫" |

### 1.1 用户痛点

- 现有AI应用界面冷冰冰，缺乏情感连接
- 初中生自控力尚在发展中，容易沉迷手机娱乐
- 学习遇到困难时缺少即时辅导
- 家长难以实时了解孩子的手机使用情况
- 希望有一个有趣的陪伴角色，而非说教式管理工具

### 1.2 设计原则

- **宠物优先**：产品核心体验是"养一只猫"，AI和管理能力是猫的"技能"，不是独立功能页
- **温和引导**：不强制、不说教，通过猫的语气和行为自然影响
- **未成年人保护**：内容安全过滤、学习引导（不给直接答案）、防沉迷
- **隐私至上**：所有使用数据本地处理，不上传服务器
- **低耗运行**：适配P30硬件条件，不跑本地模型，轻量动画

## 二、角色与动画系统

### 2.1 角色设计

| 属性 | 描述 |
|---|---|
| 形象 | 罗小黑（黑色小猫，大眼睛，圆润身体） |
| 性格 | 好奇、调皮、偶尔傲娇、喜欢窝在角落、对主人依赖 |
| 说话风格 | 口语化、简短、带猫的语气词（"喵~"、"哼"等） |
| 称呼用户 | "小主人" |
| 人设文档 | 独立配置文件（JSON），可后续替换为其他角色 |

### 2.2 动画资源清单

| 类别 | 数量 | 示例 |
|---|---|---|
| 待机 | 3-5个 | 趴着睡觉、坐着舔爪、发呆眨眼 |
| 点击回应 | 3-5个 | 被摸头开心、被戳生气、害羞躲开 |
| 拖拽 | 1-2个 | 被拎起来四肢下垂、挣扎 |
| 日常事件 | 10-15个 | 追蝴蝶、玩毛线球、打哈欠、伸懒腰、吃饭 |
| 学习相关 | 5-8个 | 看书、写作业思考、拿笔、翻页、困了趴桌上 |
| 节日/季节 | 5-8个 | 春节、生日、冬天缩成一团、夏天扇风 |
| 提醒类 | 3-5个 | 拍屏幕引起注意、举牌子、着急踱步 |

### 2.3 动画技术规格（P30适配）

| 属性 | 值 | 说明 |
|---|---|---|
| 格式 | WebP 逐帧动画 | Android原生支持，解码比WebM轻量 |
| 分辨率 | 320×320 | 手机屏幕小，不需要640×360 |
| 帧率 | 15fps | 省电，猫的动作不需要24fps |
| 透明通道 | 支持 | WebP原生支持alpha |
| 总素材体积 | < 20MB | 控制包体 |

### 2.4 动画调度规则

动画选择基于以下条件动态计算权重：

- **动画池**：Idle（待机）/ Click（点击）/ Drag（拖拽）/ Event（事件）/ Study（学习）/ Festival（节日）/ Remind（提醒）
- **基础权重**：每个动画有基础出现概率
- **时间条件**：早晨 / 上午 / 下午 / 晚上 / 深夜，不同时段不同动画
- **事件触发**：学习开始/结束、到饭点、长时间未操作、充电中
- **学习模式联动**：做作业时只播安静类动画（看书、思考），不播剧烈动作
- **节日/季节加成**：春节、生日等特殊日期触发专属动画

## 三、交互设计

### 3.1 悬浮窗宠物

| 功能 | 说明 |
|---|---|
| 悬浮显示 | `TYPE_APPLICATION_OVERLAY` 悬浮窗，始终在所有应用之上 |
| 透明穿透 | 透明区域点击穿透到下层应用 |
| 拖动 | 长按拖拽到屏幕任意位置，松手停留 |
| 点击 | 单击触发回应动画 + 随机一句话 |
| 双击 | 展开/收起输入框（和猫聊天） |
| 长按 | 弹出菜单（设置/喂食/学习模式/隐藏） |
| 尺寸 | 默认约屏幕宽度1/4，可在设置中调整30%-100% |

### 3.2 气泡对话

| 属性 | 说明 |
|---|---|
| 触发方式 | 猫主动开口 / 点击回应 / 学习提醒 |
| 显示效果 | 圆角气泡，逐字显示，3-5秒自动消失 |
| 位置 | 猫的头顶上方 |
| 字体 | 圆润可爱体，字号适中 |
| 气泡队列 | 多句话排队显示，不重叠 |

### 3.3 输入聊天

- 双击宠物 → 底部弹出输入框
- 输入消息 → 发送给外部AI模型 → 回复显示在气泡中
- 快捷按钮："帮我检查作业"、"讲个故事"、"陪我聊天"
- 支持语音输入（可选，P3）

### 3.4 右键/长按菜单

| 菜单项 | 说明 |
|---|---|
| 喂食 | 给猫喂食，增加饱腹度 |
| 学习模式 | 进入/退出学习模式 |
| 今日报告 | 查看今天的使用总结 |
| 设置 | 进入设置页面 |
| 隐藏 | 临时隐藏宠物（15分钟后自动回来） |

## 四、AI能力（外部模型接入）

### 4.1 模型接入方案

| 属性 | 说明 |
|---|---|
| API选择 | 支持配置 DeepSeek / 通义千问 / 豆包等国产API（P30无GMS） |
| 人设注入 | System Prompt 注入罗小黑的性格、语气、称呼用户为"小主人" |
| 上下文记忆 | 保留最近N轮对话（本地SQLite加密存储） |
| 安全过滤 | API层 + 本地关键词双层过滤，屏蔽不适合未成年内容 |
| 离线降级 | 无网络时，猫只能说预设的本地台词（50+句） |
| 超时处理 | API请求超时10秒，猫说"小主人等一下，罗小黑在想..." |

### 4.2 学习辅助能力

| 能力 | 实现方式 | 教育原则 |
|---|---|---|
| 作业问答 | 拍照/截图 → OCR识别题目 → 发给模型 → 返回解题思路 | 引导思考，不直接给答案 |
| 知识讲解 | "帮我解释一下什么是二次函数" → 模型用通俗语言讲解 | 用初中生能理解的语言 |
| 英语对话 | 切换英语模式，猫用英语聊天 | 帮助练习，纠正简单语法 |
| 作文灵感 | "帮我写个作文开头" → 模型提供灵感方向 | 只给方向，不给全文 |
| 错题整理 | 对话中的题目自动归类保存到"错题本" | 方便复习 |

### 4.3 主动说话

| 场景 | 触发条件 | 示例台词 |
|---|---|---|
| 早晨第一次解锁 | 6:00-10:00首次 `USER_PRESENT` | "小主人早上好~罗小黑等你好久啦！" |
| 学习时间到 | 到设定学习时间 | "该写作业啦，罗小黑陪你一起~" |
| 长时间玩游戏 | 游戏类App使用超30分钟 | "小主人玩了好久了，眼睛要休息一下喵..." |
| 到饭点 | 11:30/17:30前后 | "肚子饿了...小主人有没有好好吃饭呀？" |
| 深夜还在用手机 | 22:00后屏幕仍亮 | "太晚啦，该睡觉了喵，明天还要上学呢" |
| 回来欢迎 | 屏幕熄灭超30分钟后点亮 | "小主人回来啦！罗小黑好想你~" |
| 电量低 | 电量低于20% | "小主人，手机快没电了，罗小黑也要没电了喵..." |

## 五、手机使用检测与管理

### 5.1 使用信息采集

| 检测项 | 方式 | 用途 |
|---|---|---|
| 屏幕亮灭 | `ACTION_SCREEN_ON/OFF` 广播 | 判断使用/离开 |
| 解锁事件 | `ACTION_USER_PRESENT` | 判断开始使用 |
| 前台应用 | `UsageStatsManager` | 统计各App使用时长 |
| 使用总时长 | 累计屏幕亮起时间 | 每日使用报告 |
| 深夜使用 | 时段判断（22:00-6:00） | 健康提醒 |
| 充电状态 | `ACTION_BATTERY_CHANGED` | 电量管理 |

### 5.2 使用管理

| 功能 | 说明 |
|---|---|
| 学习模式 | 设置学习时间段（如19:00-21:00），期间猫安静陪伴，减少干扰动画 |
| 娱乐时长提醒 | 检测游戏/视频类App使用超时，猫温和提醒 |
| 深夜睡眠提醒 | 22:00后持续使用，猫多次提醒，可升级为通知 |
| 每日报告 | 每天晚上总结：学习时长、娱乐时长、休息情况，猫用对话方式讲出来 |
| 周报趋势 | 本周对比上周的变化，鼓励进步 |

### 5.3 数据存储

- **本地存储**：SQLite，记录每日App使用明细、学习时长、对话历史
- **不上传**：所有使用数据仅本地处理，不上传任何服务器
- **导出**：支持导出为图片/文本，方便家长查看（可选功能）

## 六、宠物养成系统

| 功能 | 说明 |
|---|---|
| 喂食 | 点击"喂食"按钮，猫吃东西动画，增加饱腹度 |
| 饱腹度 | 随时间下降，过低时猫表现饿、没精神 |
| 好感度 | 互动（点击/聊天/完成学习任务）增加好感度 |
| 等级 | 好感度达标升级，解锁新动画/新台词/新皮肤 |
| 状态显示 | 饥饿值/心情值/好感度，过低时猫的表现变化 |
| 学习奖励 | 完成一次学习任务，获得"小鱼干"奖励，可用来喂猫 |
| 皮肤系统 | 达到一定等级解锁新皮肤（如罗小白、节日服装等） |

## 七、通知与提醒

| 提醒类型 | 触发条件 | 表现 |
|---|---|---|
| 学习提醒 | 到设定学习时间 | 猫动画 + 气泡 + 通知栏 |
| 休息提醒 | 连续使用超40分钟 | 猫拍屏幕动画 + 气泡 |

| 电量提醒 | 电量低于20% | 猫担心表情 + 通知 |
| 生日提醒 | 用户生日 | 特殊动画 + 祝福台词 |

## 八、安全与隐私

### 8.1 内容安全

- **未成年人保护**：AI回复经过安全过滤，不涉及成人/暴力/不良内容
- **学习引导**：作业辅助只给思路不给答案
- **防沉迷**：娱乐App超时提醒，不可关闭（除非家长密码）

### 8.2 数据隐私

- 所有使用数据仅本地存储
- 对话记录本地加密存储
- 不收集位置、通讯录等敏感信息
- API请求只发送对话内容，不发送手机使用数据

### 8.3 家长模式（可选）

- 设置家长密码，可查看使用报告
- 可设置学习时间段和娱乐限制
- 不可查看对话内容（保护孩子隐私）
